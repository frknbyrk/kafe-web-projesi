# hisar kafe - Web Sitesi Projesi

Bu proje, **BLM2537 Ağ Tabanlı Programlamaya Giriş** dersi dönem projesi kapsamında geliştirilmektedir.

## Proje Hakkında
hisar kafe, kullanıcıların menüyü ve ürün fiyatlarını inceleyebileceği, kafe ile iletişim kurabileceği basit ve kullanıcı dostu bir kafe web sitesidir. İlerleyen haftalarda rezervasyon ve dinamik içeriklerin eklenmesi planlanmaktadır.

## Proje Sayfaları (1. Hafta Durumu)
Projede şu an için temel HTML sayfaları ve temel CSS tasarımı oluşturulmuştur:
- `index.html`: Kafenin ana sayfası ve tanıtım alanı.
- `menu.html`: Kahve ve tatlıların fiyatlarıyla listelendiği menü tablosu.
- `iletisim.html`: Kullanıcıların mesaj iletebileceği iletişim formu ve adres bilgileri.
